源码：[rinspacehq/rinspace-docs](https://github.com/rinspacehq/rinspace-docs) · `content/docs/`

## 在 GitHub 上修改

1. 编辑 `content/docs/*.mdx`。正文使用 Markdown，文件顶部设置 `title` 和 `description`。
2. 新页面加入 `content/docs/meta.json` 的 `pages` 列表。
3. 提交 Pull Request；合并到 `main` 后自动更新 `/docs`。

内部链接使用相对路径，例如 `./architecture.mdx`。

## 本地预览

```bash
npm ci
npm run dev
```

地址：`http://localhost:3000/docs/`。提交前运行 `npm run typecheck` 和 `npm run build`。
